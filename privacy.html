Privacy Policy

Effective date: November 20, 2026. This policy describes the desktop application GTA6 AutoClips and its informational website.

In brief: This website does not ask you to sign in or collect account credentials. The desktop app may access public clip metadata and process video/audio when you use it. TikTok account access requires your explicit authorization.

1. Who operates the project

GTA6 AutoClips is an independent software project maintained by the GitHub account glare-bot. The website is informational; the actual clip-processing software runs on the user's computer.

2. Information the desktop application may process

  • Public creator content: clip URLs, streamer names, titles, game categories, public engagement metrics, and downloaded media selected for processing from supported services such as Twitch or Kick.
  • Video and audio content: frames, speech transcripts, audio samples, proposed captions, content-safety warnings, and edit results.
  • TikTok connection information: OAuth access and refresh tokens, permission scopes, upload identifiers and status responses obtained after a user authorizes the connection.
  • Local operational records: settings, processing logs, clip history, and records used to avoid duplicate uploads and compare editing outcomes.

3. Why the information is used

The information is used to identify relevant GTA VI moments, make edit suggestions, produce videos, reduce duplicated uploads, help identify potentially unsuitable material, and send drafts or approved posts to a connected TikTok account when the user enables that function.

4. AI and third-party services

Depending on which optional features are enabled, the software can send selected clip frames, audio samples, transcripts, and related context to external AI or recognition providers such as Google Gemini and music recognition services. Twitch, Kick, TikTok, and other service providers independently process information under their own privacy policies. Their availability and data retention practices are not controlled by GTA6 AutoClips.

When TikTok upload is enabled, media files and relevant post metadata are transmitted to TikTok through its official API. The app uses OAuth and does not request or store a user's TikTok password.

5. Where information is kept

Application settings, temporary processing files, generated videos, processing history, and TikTok tokens are intended to reside on the user's own computer. The project website does not run an account database or its own analytics tracker. GitHub, as the website host, may process technical access information under GitHub's own policies.

6. Retention and deletion

Locally generated files and logs remain until the user deletes them or the application cleans up temporary files. Users can stop using the software, delete local project data, remove the saved TikTok token file, and revoke app access in their TikTok account settings. Revoking authorization stops future authorized API access but does not automatically remove previously published posts.

7. Sharing and sale

The project does not operate a business selling personal information. Information is transmitted only as needed for enabled functionality, including to the selected platform or third-party analysis providers described above. Users should avoid processing private or unauthorized material.

8. Security and limitations

Keep API keys, OAuth tokens, client secrets, and local project folders secure. Do not upload them to a public GitHub repository. No software can promise perfect protection or perfect automated content moderation.

9. Your choices

Users control whether to connect TikTok, select clips, enable optional analysis features, retain local generated media, or publish content. For questions about TikTok data, users can also consult TikTok's Privacy Policy.

10. Contact and changes

To ask about privacy, report a problem, or request removal of content operated by this project, contact the maintainer via GitHub Issues. Do not post sensitive information in public issues. This policy may change as the software's features change; updates will be posted at this URL with a revised effective date.

This policy must be reviewed and updated by the project operator if the actual deployment, contact method, storage practices, or enabled providers differ from what is described here.
